# Security Policy

Modul memerlukan root dan dapat memengaruhi boot serta display. Preview **tidak didukung untuk penggunaan umum**. Gunakan hanya pada firmware dengan fingerprint yang tepat, dengan akses recovery yang tersedia.

Jangan menonaktifkan SELinux, thermal protections, verified boot, atau spoof DRM untuk mengaktifkan fitur. Hindari permintaan yang memerlukan instruksi untuk bypass lisensi atau pembatasan keamanan sistem.

Laporkan crash/log secara tersanitasi melalui GitHub Issues, jangan unggah serial/IMEI/token/screenshot berisi data pribadi. Tidak ada jaminan rollback otomatis berhasil bila boot gagal sebelum userspace.
